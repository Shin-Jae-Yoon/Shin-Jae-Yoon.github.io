# 출처 구분

지식 항목의 내용은 셋 중 하나에서 온다. **어느 것에서 왔는지가 문서에서 보여야 한다.** 섞이면 이 저장소는 두 번째 뇌가 아니라 남의 백과사전이 된다.

| 출처                    | 어디에           | 누가                 |
| ----------------------- | ---------------- | -------------------- |
| 원본 (강의, 도서, 메모) | 본문 전체        | `knowledge-miner`    |
| 웹                      | `## 참고` 섹션만 | `knowledge-scout`    |
| 검증 결과               | 프론트매터       | `knowledge-verifier` |

## 본문은 원본만

**본문의 모든 문장은 `content/brain/{lectures,books,notes}`에 근거가 있어야 한다.** 웹에서 온 내용을 본문에 섞지 않는다. 한 문단만 섞여도 사용자가 자기 글을 다시 읽을 때 어디까지가 자기 말인지 알 수 없게 된다.

원본에 없지만 있어야 할 내용은 본문에 쓰지 않고 `## 참고`로 보낸다.

## `## 참고`

웹에서 가져온 것만 들어간다. `## 한계` 다음, `## 관련` 앞에 온다.

```markdown
## 참고

원본에는 자바 8 기준으로만 적혀 있다. 자바 21부터는 가상 스레드가 들어와
`synchronized` 블록 안에서 스레드가 고정되는 문제가 생긴다.
[JEP 444](https://openjdk.org/jeps/444)

`min.insync.replicas`의 기본값은 브로커 3.0부터 바뀌었다.
[Kafka 문서](https://kafka.apache.org/documentation/#brokerconfigs)
```

규칙은 셋이다.

- **문단마다 링크를 단다.** 링크 없는 문단은 이 섹션에 있을 수 없다
- **1차 출처만.** 공식 문서, 명세, 원저자의 글, 소스 코드. 블로그 요약글은 징검다리로만 쓰고 인용하지 않는다
- **버전을 적는다.** "자바에서는"이 아니라 "자바 17부터"다

이 섹션이 없는 항목이 정상이다. 원본으로 충분하면 만들지 않는다.

## `## 출처`

원본 위키링크. 지금까지와 같다.

```markdown
## 출처

- [[brain/books/kafka/chap07|카프카 핵심가이드 7장 - 신뢰성 있는 데이터 전달]]
```

`## 참고`의 웹 링크를 여기 섞지 않는다. 이 섹션은 사용자가 읽은 것만 적는 자리다.

## 프론트매터

```yaml
---
title: 멱등적 프로듀서
aliases:
  - 멱등적 프로듀서
tags:
  - messaging
  - kafka
origin:
  mined: 2026-08-30 # 원본에서 뽑은 날
  verified: 2026-08-30 # 검증을 통과한 날. 통과 전에는 적지 않는다
  scouted: 2026-08-30 # ## 참고 가 있을 때만
---
```

`verified`가 없으면 아직 검증 전이다. **검증에 실패한 항목에는 날짜를 적지 않는다.** 실패를 감추면 이 필드가 아무 뜻도 없어진다.

원본이 바뀌면 `verified`를 지운다. 검증은 그때의 원본에 대한 것이지 영구 보증이 아니다.

## 세 에이전트가 도는 순서

```
knowledge-miner    원본을 읽고 본문을 쓴다. 원본에 없어 못 쓴 것을 목록으로 남긴다
        ↓
knowledge-verifier 본문의 각 문장을 원본과 대조한다. 근거없음이 있으면 반려
        ↓
knowledge-scout    miner 가 남긴 목록만 웹에서 찾아 ## 참고 에 넣는다
        ↓
knowledge-verifier ## 참고 의 링크가 실제로 그 내용을 담고 있는지 다시 본다
```

scout 을 miner 보다 먼저 돌리지 마라. 원본에 무엇이 있는지 모르는 채로 웹을 뒤지면 원본에 있는 내용을 웹 설명으로 덮어쓴다.

## 검사

```bash
node tooling/brain/knowledge-provenance.mjs
```

`## 참고` 문단의 링크 유무, `## 출처` 경로의 실재, `origin` 필드의 형식, 검증 안 된 항목 수를 센다.

형식과 문체는 [knowledge-note](../knowledge-note/SKILL.md) 스킬이 맡는다.
